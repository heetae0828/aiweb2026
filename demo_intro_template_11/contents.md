## 문제

시험 범위는 주어졌지만 어떤 문제가 나올지 몰라서, 준비할 때 예상 문제를 직접 만들기 어렵고 자신의 약점을 체계적으로 관리하기 어려운 대학생 학습 부담을 해결한다. AI가 과목 자료를 분석해 예상 문제를 제공하고 자동 채점까지 수행하며, 푼 문제의 소요 시간과 결과를 누적해 오답 노트와 자주 틀리는 유형을 알려준다.

---

## 사용자

주로 대학생이 사용하는 서비스이며, 학과 제한 없이 시험 범위를 받아 공부하는 누구나 사용할 수 있다. 특히 문제 출제 형태를 예측하고 오답 원인을 빠르게 파악하고 싶은 학생에게 유용하다.

---

## 핵심 기능 (3개 이하)

1. 사용자가 제공하는 시험 대비 수업 자료 파일을 읽고 학습 구조와 공부 범위를 파악한 뒤, 단답형·서술형·객관식 형태의 예상 문제를 생성한다.
2. 수업 자료와 별도로 참고 자료로 제공된 파일을 분석해 오답 노트와 학습 보충 설명에 활용하며, 해당 자료는 시험 문제 출제에 직접 사용하지 않는다.
3. 사용자가 푼 시험 문제 결과를 최대 100개까지 누적 저장하고, 자주 틀리는 문제를 자동으로 분석해 다시 설명과 학습 팁을 제공한다.

> 못 줄이면 진짜 핵심 1개만 골라도 OK. 5~7개로 늘리면 강사 ✗.

---

## 입력 → AI 처리 → 출력

1. 입력: 시험 문제 생성을 위한 수업 자료, 오답 노트 및 질문 답변용 참고 파일, 사용자의 문제 풀이/질문 프롬프트
2. 처리: 수업 자료를 분석해 출제 범위와 학습 흐름을 파악하고, GPT API로 예상 문제를 생성한다. 참고 파일은 문제 출제가 아닌 추가 정보로 활용해 오답 노트와 질문 답변의 근거로 사용한다.
3. 출력: 교수자의 입장에서 정제된 예상 문제, 채점 결과, 풀이 시간 기록, 오답 노트 요약과 자주 틀리는 문제 분석을 제공한다.

## 기술 스택

- **UI**: Gradio
- **모델 / API**: OpenAI GPT-4o-mini (OpenAI API, `OPENAI_API_KEY` 환경변수 사용)
- **외부 서비스**: 없음 (또는 로컬/간단 파일 저장으로 구현)

> 주의: API 키는 `.env` 같은 환경 변수 파일에만 저장하고, 깃 커밋이나 공개 저장소에는 절대 업로드하지 않는다.

---

## 데이터 출처

- 사용자가 직접 제공한 수업 자료 파일(교재 요약, 강의 노트, 슬라이드, PDF 등)
- 사용자가 별도로 제공하는 참고 자료 파일(추가 설명서, 예제 문제, 해설 노트 등)

⚠️ 저작권·개인정보 위반 데이터는 사용하지 않는다.

---

## 완료 조건

- 사용자가 수업 자료 파일과 참고 파일을 업로드하면 30초 이내에 10개 이상의 예상 문제(단답형·서술형·객관식)를 생성한다.
- 사용자가 제출한 답안에 대해 자동 채점 결과와 풀이 시간을 기록하고, 최대 100개의 문제 결과를 누적하여 오답 노트와 자주 틀리는 문제 유형을 제공한다.
- 자주 틀리는 문제에 대해 다시 설명을 생성하여 학습 보완 정보를 출력한다.

❌ "잘 작동한다" / "괜찮게 나온다" — 측정 불가
✅ "입력 A를 넣으면 출력 B가 X초 이내에 나온다" — 측정 가능
